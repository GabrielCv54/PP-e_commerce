## Ecompre - Projeto de um ecommerce com NextJS
<img src="/frontend/ecompre/public/logo_ecompre.png" width="50%" height="50%">

Ecompre📦
Realizei esse projeto para reforçar e aprender um pouco mais dos conceitos do Framework NextJS, , login(admin, usuário), e visualização de produtos cadastrados no banco de dados. Cada página foi construída

## Tecnologias Utilizadas
Front-end
- React ⚛️
- Next-js ▲
- Tailwind CSS🎨

Back-end
-  Python 🐍
- Flask 
- SQLite 🛢

### Como baixar
` git clone https://github.com/GabrielCv54/PP-e_commerce.git`


## Como executar(back-end)
- Abra o terminal 
- digite 'cd backend'
- Digite 'python app.py'

## Como executar(front-end)
- Abra outro terminal
- Lá digite `cd frontend ` e digite enter.
- Agora que está na pasta frontend, digite ` cd ecompre `.
- rode o comando `npm run dev `, e logo após abra o link localhost:3000 no navegador
